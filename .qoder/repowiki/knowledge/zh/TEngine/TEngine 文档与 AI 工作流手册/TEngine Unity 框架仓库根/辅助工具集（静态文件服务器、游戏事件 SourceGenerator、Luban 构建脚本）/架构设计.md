本模块是横向工具集合，各子目录彼此独立、无相互依赖：
- `FileServer/`：基于 Node.js 的静态文件服务器，入口为 `index.js` → `bin/app.js`，通过 `package.json` 暴露 `server` CLI；模板渲染使用 Handlebars，MIME 类型由内置 `mime.js` 处理，支持 HTTPS（pem）、自动打开浏览器（open）。
- `GameEventSourceGenerator/`：包含两个 .NET SDK 项目——`GameEventAnalyzer`（netstandard2.0，依赖 Microsoft.CodeAnalysis.CSharp 3.8.0，实现诊断与 CodeFix）和 `SourceGenerator`（netstandard2.0，依赖 3.9.0，复用 Analyzer 下的 Extension 代码），两者均标记 `DevelopmentDependency=true`，作为开发期 NuGet 包被 Unity/C# 工程引用；Solution 文件 `SourceGenerator.sln` 同时管理二者。
- `Luban/`：仅含占位 `about.txt`，实际二进制通过根级 `build-luban.sh` / `build-luban.bat` 从上游 `focus-creative-games/luban` 仓库克隆并 `dotnet build` 输出到 `Tools/Luban` 目录。
依赖方向单向向外：本模块不依赖 TEngine 主工程，而是被主工程在开发阶段消费。
