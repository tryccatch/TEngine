### TEngine
- 定义：本项目的正式名称——一个基于 Unity 的全平台游戏框架解决方案，内置资源管理（YooAsset）、事件系统、UI 框架、配置表（Luban）、流程模块与 HybridCLR 热更新支持。

### HybridCLR
- 定义：项目中用于实现全平台 C# 热更新的 Unity 插件（com.code-philosophy.hybridclr）。TEngine 通过编辑器菜单（Install / Define Symbols / Generate / Build）组织完整的热更新构建流程。
- 别名：热更新、HybridCLR 热更新

### Luban
- 定义：项目中用于生成配置表的工具链，支持懒加载、异步加载、同步加载，配置文件位于 `Configs/GameConfig/Datas/*.xlsx`，由 `luban.conf` 驱动代码生成。
- 别名：配置表、配置表系统

### YooAsset
- 定义：项目中用于资源管理的第三方框架，支持 LRU/ARC 缓存策略、EditorSimulateMode、OfflinePlayMode、HostPlayMode 等多种运行模式。
- 别名：资源模块、ResourceModule

### ZZZ Kit
- 定义：项目使用的 Unity Package Manager 安装器（com.zzz.kit），负责自动安装依赖包；当工程内已嵌入 com.unity.pipeline 时会因无法覆盖而报错。
- 别名：com.zzz.kit、安装器

### AI 开发工作流
- 定义：项目采用的「需求确认 → 实现 → 自动验证 → 审查 → 证据交付」闭环流程，本地与 CI 共用，通过 Unity CLI 获取真实 Editor 结果，入口为 `python .codex/scripts/workflow.py doctor/check/verify`。
- 别名：工作流、workflow

### MCP unity 工具集
- 定义：通过 MCP（Model Context Protocol）暴露给 AI 工具的 Unity 操作集合，包含 script_recompile、script_eval_file、capture_screenshot 等能力，受 com.unity.pipeline 版本约束。
- 别名：MCP、unity 工具集

### .codex
- 定义：项目根下的 AI 辅助开发目录，包含 skills、references、scripts（workflow.py、workflow_lib/unity.py）等，定义 TEngine、Unity 操作、Luban、HTML→UGUI 四项技能及自动化验证契约。
- 别名：codex、skills
